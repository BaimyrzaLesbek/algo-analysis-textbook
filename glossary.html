Glossary of key terms

Terms in alphabetical order. The link after each term points to the section where it is explained.

Accumulator
An extra parameter that carries a partially computed result through recursive calls, used to make a function tail-recursive. Module 2 §6
Average case \(C_{avg}(n)\)
The expected number of basic operations on a random input of size \(n\), under a stated probability model of the inputs. Intro §5, Module 1 §5
Backward substitution
A method of solving a recurrence: repeatedly replace \(x(n-1)\) (or \(x(n/2)\)) by its own recurrence, find the general pattern after \(i\) steps, and choose \(i\) to reach the initial condition. Module 2 §2
Basic operation
The operation that contributes most to the running time, usually the most time-consuming operation in the innermost loop. We count how many times it is executed. Intro §2
Best case \(C_{best}(n)\)
The minimum number of basic operations over all inputs of size \(n\). Intro §5
Big-O, \(O(g(n))\)
The set of functions that grow no faster than \(g(n)\): \(t(n) \le c\,g(n)\) for all \(n \ge n_0\). Intro §4
Big-Omega, \(\Omega(g(n))\)
The set of functions that grow no slower than \(g(n)\): \(t(n) \ge c\,g(n)\) for all \(n \ge n_0\). Intro §4
Big-Theta, \(\Theta(g(n))\)
The set of functions that grow at the same rate as \(g(n)\): both \(O(g(n))\) and \(\Omega(g(n))\). Intro §4
Closed-form formula
An explicit formula with a fixed number of operations, without \(\sum\) signs or references to other values of the function, e.g. \(\frac{n(n+1)}{2}\). Module 1 §1
Recursion depth
The maximum number of recursive calls that are active (on the stack) at the same time. It determines the extra memory of a recursive algorithm. Module 2 §6
Empirical verification
Checking a formula by running a program with an operation counter and comparing the counted values with the formula. Module 1 §7
Geometric series
A sum \(1 + a + a^2 + \dots + a^n = \frac{a^{n+1} - 1}{a - 1}\) (\(a \ne 1\)). Module 1 §2
Mathematical induction
A proof method: show the statement for the initial value (base), then show that if it holds for smaller values it holds for \(n\) (inductive step). Used to verify solutions of recurrences. Module 2 §2
Initial condition
The value of a recurrence at its smallest argument, e.g. \(M(0) = 0\). It comes from the base case of the algorithm. Module 2 §1
Input size
A parameter \(n\) that measures how big the input is (number of elements, matrix order, or the number of bits of a number). Intro §1
Memoization
Storing the result of each subproblem the first time it is computed and reusing it instead of recomputing. Module 2 §5
Order of growth
How fast a function grows as \(n \to \infty\), ignoring constant factors and lower-order terms (e.g. \(\log n\), \(n\), \(n^2\), \(2^n\)). Intro §3
Recurrence relation
An equation that expresses \(x(n)\) through values of \(x\) at smaller arguments, e.g. \(M(n) = 2M(n-1) + 1\). Module 2 §1
Recursion tree
A diagram where each node is one call of a recursive algorithm and its children are the calls it makes. The number of nodes gives the time, the height gives the memory. Module 2 §3
Smoothness rule
If \(T(n)\) is eventually non-decreasing and \(T(n) \in \Theta(f(n))\) for \(n = 2^k\), where \(f\) is a "smooth" function such as \(\log n\), \(n\), \(n\log n\), \(n^2\), then \(T(n) \in \Theta(f(n))\) for all \(n\). Module 2 §3
Stack frame
The memory kept for one active call: parameters, local variables and the return address. Module 2 §6
Summation (\(\sum\)) notation
\(\sum_{i=l}^{u} a_i = a_l + a_{l+1} + \dots + a_u\); \(i\) is the index, \(l\) and \(u\) are the bounds. Module 1 §2
Tail recursion
Recursion in which the recursive call is the last action of the function. It can be turned into a loop with constant stack depth. Module 2 §6
Worst case \(C_{worst}(n)\)
The maximum number of basic operations over all inputs of size \(n\); a guarantee that the algorithm never does more. Intro §5
