Mathematical Analysis of Algorithms

An e-textbook for bachelor's students: how to count the work done by nonrecursive and recursive algorithms, and how to turn that count into an order of growth.

Who is this for?

Second-year bachelor's students who already know basic programming (loops, arrays, functions) and have seen the idea of "big-O". Every new term is explained the first time it appears, and each one is also collected in the glossary.

How to use this textbook

  1. Take the entry quiz. If you score less than 4 / 5, read the introduction carefully first.
  2. Read a module from top to bottom. Each worked example follows the same five steps, so after two or three examples you will start seeing the pattern.
  3. Do the module quiz. Every answer option has an explanation, so read them even when you answered correctly.
  4. Solve the problems in order A → B → C. Each problem has a hint, an answer and a full solution hidden behind buttons. Try first, then open the hint, and open the solution only at the end.
  5. Run the Python code for the empirical tasks and check that the numbers match the formulas.
Notation used

Pseudocode follows the notation of A. Levitin's textbook: ← is assignment, arrays are written \(A[0..n-1]\), and for i ← 0 to n − 1 do includes both ends. Program code is in Python. \(\log n\) without a base means \(\log_2 n\) unless stated otherwise.
